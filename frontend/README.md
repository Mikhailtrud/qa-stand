# Frontend

React frontend для проекта QA Sandbox.

## Стек

- React
- React Router
- Vite
- Fetch API
- Docker

---

## Возможности

- Авторизация
- Dashboard
- Управление пользователями
- QA Playground
- Маршрутизация
- Bearer Token авторизация

---

## Запуск локально

```bash
npm install
npm run dev
```

---

## Сборка

```bash
npm run build
```

---

## Приложение

```
http://localhost:5173
```
